# Maze Game

## Project Description

Maze Game is an interactive and engaging browser-based puzzle challenge designed to test your navigation skills. The application dynamically generates a unique and solvable maze layout every single time you start a new game session. Players can effortlessly guide the character from the starting point to the final destination portal using either on-screen arrow buttons or keyboard strokes. A built-in move tracker records every single step you take to help you monitor your efficiency and problem-solving strategy. When you finally reach the exit, a celebratory modal pops up to display your total moves and congratulate you on your victory. Entirely self-contained and lightweight, this project offers a smooth, fun, and responsive gaming experience right inside your web browser.

## Features

 * Fully responsive layout optimized for various screen sizes.
 * Dynamic maze generation algorithm ensuring a unique puzzle layout per game.
 * Interactive on-screen D-pad arrow buttons for mouse and touch navigation.
 * Full keyboard support utilizing arrow keys and WASD inputs.
 * Live move counter tracking player progress in real time.
 * Congratulatory win screen modal displaying final game statistics.
 * Quick-reset functionality to instantly restart or generate a new maze.

## Technologies Used

- **Frontend Structure:** HTML
- **Styling & Presentation:** HTML (using built-in elements and attributes)
- **Game Logic:** HTML
- **Game Type:** Maze Game

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

- A modern web browser (Google Chrome, Firefox, Edge, or Safari).
- A code editor (Visual Studio Code, Notepad++, or any text editor).

### Installation

1. Create or download the project folder containing the maze game HTML file.
2. Navigate to the project directory.
3. Open the `index.html` file in your preferred code editor.
4. Save the HTML file if you make any changes.
5. Open `index.html` in your web browser to launch the game.

## Usage

To play the Maze Game, open the application in your web browser and navigate through the maze from the starting point to the finish. Avoid dead ends and find the correct path to reach the destination. The game provides a simple and interactive way to enjoy a maze puzzle using HTML.
